## Rebuilding / editing this cut

Everything is data-driven in `remotion/think14/reel/edit.ts` — segments, crops, punch values, caption timings and callouts are plain arrays. Change a crop or a caption there and re-render:

```bash
npx remotion render remotion/index.ts Think14Reel out/think14-reel-9x16.mp4 --crf=23
```

### ffmpeg equivalent (if the editor prefers a CLI pass)
Per segment, crop then scale then pad into the vertical canvas:

```bash
ffmpeg -i source.mp4 -ss 11.0 -to 21.98 \
  -vf "crop=1760:990:60:60,scale=1080:-2,pad=1080:1920:0:(1920-ih)/2:white,setsar=1" \
  -c:v libx264 -crf 20 -c:a aac seg04.mp4
```

Repeat per row of the table, then concat:

```bash
printf "file '%s'\n" seg*.mp4 > list.txt
ffmpeg -f concat -safe 0 -i list.txt -c copy reel.mp4
ffmpeg -i reel.mp4 -vf "subtitles=think14-reel-captions.srt:force_style='Fontsize=18,Bold=1'" -c:a copy reel-captioned.mp4
```
